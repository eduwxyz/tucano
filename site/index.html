PerguntasFAQ
O que todo mundo pergunta primeiro.What everyone asks first.

    

      
Quanto custa?How much does it cost?
Nada. O Tucano é grátis, sem recurso trancado. Você usa o plano do Claude ou do ChatGPT que já paga, os seus provedores, ou o gateway da empresa.Nothing. Tucano is free, with no locked features. You use the Claude or ChatGPT plan you already pay for, your own providers, or your company’s gateway.

      
Preciso de chave de API?Do I need an API key?
Não. Ele roda o Claude Code, o Codex, o OpenCode ou o Pi já configurados no seu computador. O app nunca vê nem guarda a sua senha.No. It runs Claude Code, Codex, OpenCode or Pi as they’re already set up on your computer. The app never sees or stores your password.

      
É seguro deixar agentes mexendo nas coisas?Is it safe to let agents touch things?
Cada agente só usa o que recebeu, ações sensíveis pedem o seu sim (amarrado àquela ação exata) e os comandos rodam num Linux isolado, a não ser que você escolha dar o seu computador.Each agent only uses what it was given, sensitive actions need your yes (tied to that exact action), and commands run on an isolated Linux machine, unless you choose to hand over your own computer.

      
Onde ficam os meus dados?Where does my data live?
No seu computador: conversas, memória, arquivos e logins. O modelo recebe só o que os agentes mandam pra ele, pelo caminho que o seu harness já usa.On your computer: conversations, memory, files and logins. The model only receives what the agents send it, through the path your harness already uses.

      
E se o plano chegar no limite?What if my plan hits its limit?
Você define limite por agente e teto por resposta. O app confere antes de cada resposta, avisa em 80% e mostra onde cada agente vai fechar o mês no ritmo atual.You set a limit per agent and a cap per reply. The app checks before every reply, warns at 80% and shows where each agent will end the month at the current pace.

      
Roda no Linux ou no Windows?Does it run on Linux or Windows?
No Linux, sim: .deb pro Ubuntu e o Debian, AppImage pras outras distribuições, em x64 e ARM64. No Windows 10 e 11 também: cole irm …/install.ps1 | iex no PowerShell, ou baixe o .exe (sem assinatura de código, então o Windows avisa uma vez: Mais informações › Executar assim mesmo). No Mac, precisa do chip Apple (M1 ou mais novo).On Linux, yes: a .deb for Ubuntu and Debian, an AppImage for other distributions, on x64 and ARM64. On Windows 10 and 11 too: paste irm …/install.ps1 | iex in PowerShell, or download the .exe (it isn’t code-signed, so Windows warns once: More info › Run anyway). On a Mac, it needs Apple silicon (M1 or newer).
